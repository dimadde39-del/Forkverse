# User And Jobs

## Current Synthesis

The primary MonteRun user is a freelancer, solo founder, operator, or unstable-income worker who needs a fast answer to one painful question: how long do I survive if my plan meets reality?

They usually have some cash, chaotic income, recurring burn, and a decision under pressure: quitting, moving, buying, hiring, running ads, taking a client, losing a client, or waiting for payments.

## Core Jobs

- Understand months of runway from current cash and burn.
- See how fast runway collapses under stress.
- Identify the 3 to 5 levers that most improve survival.
- Compare base and stress scenarios before a real decision.
- Recalculate when income, burn, or life changes.

## First-Use Requirements

- First useful verdict should arrive in under 60 seconds from opening the product.
- Current parser launch target is sub-10-second extraction feel.
- Input must not feel like accounting software.
- The user should know immediately where to type the scenario.
- Missing critical values should clarify instead of fabricating fake survival.

## Success Signals

- User understands the main output without a tutorial.
- User interacts with a lever or stress mode.
- User returns to recalculate when reality changes.
- Verdict feels precise rather than gimmicky.
- Share behavior does not weaken trust in the underlying math.

## Agent Caution

Do not optimize only for social shock. MonteRun's product value is repeated recalculation against reality, not one-time roast entertainment.
