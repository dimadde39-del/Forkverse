# Skills Layout

- Each subdirectory in this folder should be a real Codex skill and must contain a `SKILL.md`.
- Keep skill-specific references, scripts, templates, and assets next to that skill.
- Put vendored tools, external repos, and helper frameworks in `.agents/vendor`, not in this folder.
- Selected local skills are exposed globally through junctions in the user Codex skills directory so they remain available in future projects.
