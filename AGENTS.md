# Project Conventions

- Use the `obsidian` MCP server for note, memory, and documentation tasks that belong in the vault at `C:\ForkVerse\Obsidian`.
- Prefer project-local skills from `.agents/skills` when they match the task. Use the `forkverse` skill for product-specific architecture, API, data, Telegram bot, and deployment conventions.
- Keep only real skills in `.agents/skills`. If a directory does not contain `SKILL.md`, it belongs somewhere else such as `.agents/vendor`.
