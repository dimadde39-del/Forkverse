Назначение. Этот документ описывает одну конкретную функцию продукта MonteRun и фиксирует её цель, логику, интерфейс, правила, метрики и границы реализации для MVP.

1. Цель функции

Сделать продукт местом, куда пользователь возвращается перед реальным решением. Для этого сценарии нужно сохранять, пересчитывать и сравнивать по дельтам.

2. Основные сценарии использования

• Пользователь меняет доход и хочет увидеть новый runway.

• Пользователь планирует крупную покупку и сравнивает до/после.

• Пользователь получил новый долг или потерял клиента.

• Пользователь отслеживает эффект принятых мер за неделю или месяц.

3. Основные элементы функции

Элемент

Описание

Save scenario

Сохраняет snapshot входных данных и output.

Recalculate

Повторно считает тот же сценарий с новыми значениями.

Delta view

Показывает, как изменился runway и почему.

Scenario labels

Позволяет отмечать сценарии как Base, Plan B, Worst Month и т.д.

4. Delta view

Показывать не только новое значение, но и изменение относительно прошлого: last week runway, current runway, delta in months, main reason of change.

5. Метрики успеха

• Высокая доля пользователей делает хотя бы один recalculation.

• Повторные заходы связаны с реальным изменением параметров, а не только с чтением текста.

• Сценарии сравниваются, а не просто копятся мёртвым списком.

6. Ограничения MVP

• Без сложной аналитики по месяцам.

• Без мульти-аккаунтного shared workspace.

• Без совместного редактирования.
